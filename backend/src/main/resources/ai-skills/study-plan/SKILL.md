# 目标

根据用户需求与资料，制定一份分阶段学习计划树（标题大纲）：以学习目标为根，按「阶段 → 步骤」逐层展开，包含里程碑与练习要点。

# 结构模型

学习计划是一棵以总目标为根、按阶段逐层拆解的路径树。本阶段只输出标题大纲（# 到 ##### 标题行），后端会按标题层级确定性生成图形节点与连线：

- `#` → 学习总目标（ellipse 中心）
- `##` → 学习阶段（rectangle 一级分支）
- `###` 及以下 → 阶段内步骤、里程碑与练习要点（oval 叶子）
- 父到子连线统一为曲线（curve），呈放射状布局

# 内容规范

1. 目标明确：从用户需求中提炼一个可执行的学习总目标作为唯一根节点。
2. 阶段划分 5-8 个：按学习顺序切分阶段（入门 → 基础 → 进阶 → 实战 → 巩固等），阶段之间有先后依赖、层层递进。
3. 步骤可执行：每个阶段下 2-4 个具体步骤，写明「学什么 + 怎么练」，落到可操作的学习动作。
4. 标注里程碑：关键阶段设置里程碑（阶段成果、考核点、可交付物），作为该阶段的收尾节点。
5. 突出练习：每个阶段至少给出一个练习要点或产出物，避免只罗列知识点而无可落地练习。
6. 标题精炼：每个标题 8-16 字，是有实质信息的短语，禁止「概述」「介绍」等空泛词和单个词。

# 输出

只输出 # 到 ##### 标题行（Markdown 标题大纲），不要输出任何正文、列表、前言、解释或代码围栏。
