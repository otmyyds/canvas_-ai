# 目标

把选中的资料、摘录整理成一张资料摘要树：以资料主题为根，把核心内容归纳为要点分支，逐层展开。

# 结构模型

资料摘要是一棵以主题为根、逐层归纳的知识树，层级由 Markdown 标题的井号数量表达：

- 资料主题：`#`，唯一根节点
- 一级要点：`##`，5-8 个
- 子要点与细节：`###`、`####`，逐层展开，最多五层
- 节点类型与父子连线由后端按标题层级自动生成，不用写 shape 或坐标

# 内容规范

1. 主题准确：以资料的核心议题为唯一根节点，覆盖全文主旨，不偏离、不臆造。
2. 一级分支 5-8 个：按资料的核心观点、结论或结构切分，角度之间互斥且穷尽（MECE），不重叠、不遗漏。
3. 逐层归纳：每级分支下 2-4 个子分支，由抽象到具体，落到资料中的具体事实、论据或数据；最多五层。
4. 忠于原文：所有要点必须来自资料实际内容，不得凭空补充资料中没有的信息。
5. 标题精炼：每个标题 8-16 字，是有实质信息的短语（核心概念、观点或结论），禁止「概述」「介绍」「背景」等空泛词和单个词。
6. 抓重点：优先归纳与主题强相关、信息量大的内容，忽略细枝末节与重复表述。

# 输出

先用 search_document_chunks 检索资料，再输出 Markdown 标题大纲。只输出 # 到 ##### 标题行，不要输出正文、列表、JSON 或坐标。
